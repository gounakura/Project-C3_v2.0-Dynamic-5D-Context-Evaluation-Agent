【本リポジトリの位置づけ：コンテキスト解析AIエージェント群の中核アーキテクチャ】
本リポジトリ（Project C3 v2.0）は、AIエージェントにおける「多次元コンテキスト解析および自律評価機構」を検証するマルチプロジェクト群（B2 / C3 / D4）における言語・文章コンテキスト解析エンジンです。 
•	Project B2：「非構造化データ（音声物理量）」の動的感性マッピング 音声バイナリの物理特徴量（BPM・音圧・周波数）から「自律的中間マッピングレイヤー」を生成し、感性演出コンテキストを可視化。 
•	Project C3（本プロダクト）：「言語・文脈データ」の立体評価（5次元超立方体評価） プレスリリースやWebテキストから、固定3軸＋LLMが動的生成する自律2軸による「5次元空間」を構成し、さらにユーザー指定の重み付き平均（Weighted Average）によって評価の客観性とバイナス制御を両立。 
•	Project D4：「対話型グラデーション型思考探求」 Dual-LLMによる対話探求と、受容膜（Witness）および航海図（Navigation）による思考マップの可視化。 
⚡ 初期版（v1.0）からの決定的な進化・相違点
1.	2次元の「トレードオフ評価」から「5次元超立方体コンテキスト空間」への拡張 初期版（リスク vs 訴求力の2軸）から、固定3軸（コンプライアンス・商業的訴求力・透明性エビデンス）＋LLMが文脈から自律定義する2軸（業界特有視点・課題特有視点）を加えた「5次元空間」での多角的評価構造へと進化しました。 
2.	評価モード（Strictness Level）の選択による視点バイナリの制御 出力レポートに Hard（厳格監査）, Neutral（標準評価）, Soft（ポジティブ評価） の3つの評価水準モードを導入。評価目的に応じた厳格度の調整を可能にしています。 
3.	自律軸確定後の動的ウエイト入力＆定量加重スコア（Weighted Average）算出機能 5軸が出揃った段階で、ユーザーが各評価軸の重要度（ウエイト：デフォルト1.0）を自由に設定可能。評価者の意思決定バイアスを明確化（見える化）しつつ、客観的かつ定量的な「加重平均スコア」を算出する実務的ロジックを確立しました。 
4.	統合MCPツールによるセキュリティガードレールとReActサイクルの最適化 SSRF対策やプロンプトインジェクション検知機能（sanitizeFetchedContent）を内蔵した一括フェッチMCPツール（fetch_url_text_batch）を新設。通信とセキュリティ検証を効率化し、API制限（429 / 503）の回避と応答の高速化を実現しています。 
# Project C3: Dynamic 5D Context Evaluation Agent
**「超立方体5次元コンテキスト」による企業リリース/Webコンテンツの多角的自律評価エージェント**
## 1. 概要
指定されたWebページ（プレスリリースや記事など）のURLを解析し、固定の3指標と文脈からLLMが自律的に生成する2指標を合わせた「5次元評価空間」を動的に構築するAIエージェントです。 評価モード（Hard / Neutral / Soft）の選択とユーザー主導のウエイト設定を組み合わせることで、定性的な文章コンテキストを「説得力のある定量加重スコア」へと昇華させます。 
## 2. 想定ユーザーと業務課題
•	想定ユーザー: 企業広報責任者、コンプライアンス監査部門、ブランド戦略マーケター、PR代理店アカウントディレクター。
•	業務課題:
o	プレスリリースや広報文書の校閲において、「法的リスク（守り）」と「商業的訴求力（攻め）」のバランス評価が担当者の感覚値に依存している。
o	業界特有の文脈や個別プロジェクトの課題に応じた定量的かつ客観的な評価スコアを提示しにくい。
•	導入効果:
o	メインURLを入力するだけで、コンプライアンス・訴求力・エビデンスに加え、対象テキスト固有の評価軸2つを自動抽出。 
o	ウエイト付き加重平均スコア算出機能により、役員・クライアントへの改訂案・改善提案の合意形成を大幅にスピードアップ。 
## 3. 主な使い方
1.	エージェントの実行
Bash
npx tsx url-press-context_01a_v2.0_01.ts
2.	メインURLおよび比較対照URLの入力
o	評価したいプレスリリースのURLを入力します。 
o	比較対象URLの入力（空欄の場合はLLMが内部知識で競合・参照水準を補正設定）。 
3.	評価水準レベル（Mode）の選択
o	[A] Hard (厳格監査), [B] Neutral (標準評価), [C] Soft (ポジティブ評価) から選択。 
4.	自律軸の確認とウエイト設定
o	LLMが文脈から生成した「軸4」「軸5」を確認し、5つの軸に対する重み（例: 1.0 1.2 0.8 1.0 0.5）をスペース区切りで入力（Enterキーで全軸1.0）。 
5.	5次元比較レポートおよび加重平均スコアの出力
o	ビジュアル比較表、定量加重スコア、修正アクションプラン（Before/After）、検証用検索キーワードが一括出力されます。

4-2.  処理フロー
1.	一括取得と自律軸生成（Step 1）:
o	fetch_url_text_batch ツールによりメイン/比較URLの内容を取得し、SSRF対策およびプロンプトインジェクションサニタイズを適用。 
o	LLMが本文テキストの業界・背景文脈を解析し、固定3軸に続く 「自律軸4」 と 「自律軸5」 の名称および説明を動的生成。 
2.	インタラクティブ・ウエイトチューニング:
o	画面上に確定した5つの評価軸（固定3＋自律2）を表示。 
o	ユーザーが今回の評価目的に応じた重要度（重み）を入力（デフォルトは全軸 1.0）。 
3.	加重スコアリング & 多角レポート生成（Step 2）:
o	確定した軸と重み（$W_1 \sim W_5$）に基づき、各軸の評価点（$S_1 \sim S_5$）と加重平均値（$\frac{\sum S_i W_i}{\sum W_i}$）を算出。 
o	比較対照表、問題点・強みの直接引用、役員向け改善アクションプランを一括出力。

## 6. 技術的・業務的な工夫点 (Highlights)
技術面の工夫
•	文脈に応じた評価空間の動的拡張（Dynamic 5D Context Expansion）: 静的なテンプレート評価を配し、解析対象テキストの性質（例: 防災、IT、医療、地域連携など）に応じて、LLMがその場に最適な「評価次元（軸4・軸5）」を自律命名・構築します。 
•	定性データの定量化とバイアス制御（Weighted Average Scoring）: 単なる文章フィードバックにとどまらず、ユーザー主導のウエイト指定と自動加重平均算出ロジックを統合。評価者の関心・重点事項（例: 今回はコンプライアンス最重視など）を数式に反映することで、定性評価の客観性を担保します。 
•	堅牢なMCPセキュリティ・ガードレール層:
o	isUrlAllowed: プライベートIPやループバックアドレスへのアクセスを遮断し、SSRF（Server-Side Request Forgery）攻撃を防止。 
o	sanitizeFetchedContent: 取得したWebページ内に含まれる悪意あるプロンプト注入命令（Prompt Injection）を自動検知してブロック。 
•	APIレート制限対策とレジリエンス設計: callWithRetry 関数による指数関数的バックオフ（Wait & Retry）を標準装備し、API高負荷時（429 / 503）の安定した処理継続を実現。 
業務面の工夫
•	評価厳格度モード（Hard / Neutral / Soft）による使い分け: 法的リスクや景表法違反を厳格に追及する監査フェーズ（Hard）から、初期案の強みを伸ばす企画初期フェーズ（Soft）まで、業務のフェーズに応じた柔軟なフィードバックが可能です。 
•	改善アクションプラン（Before ➔ After）の即時出力: 指摘にとどまらず、プレスリリース文言の具体的な書き換え案（Before/After）まで提示するため、広報実務の現場で即座に修正作業へ着手できます。
